# How to play game:

On this GitHub Page for the 'game_download' branch, click the green 'code' button and choose the bottom option, 'Download ZIP'.

Once downloaded from the GitHub page, extract all files to a new directory and ensure the `ROD_interactive.exe` file and the `images` folder are in the same directory.

Double click the `ROD_interactive.exe` file to play the game! You can either click one of the 'quit' buttons on an end screen, or click the 'x' in the top right corner to close the game.

The resolution of the game is hard set to 1920x1080. It can be maximized to fit a screen, but not minimized. If it is too large for your screen, you may need to zoom out using Windows settings (see 'System' -> 'Display' -> 'Scale').

Stuck? View the `hints.txt` file downloaded with the rest of the files.

NOTE: The .exe (executable) of this game can only be run on a Windows machine. To view the original .rb (ruby) version of the game that can be run via command line on any operating system, view the 'main' branch.
